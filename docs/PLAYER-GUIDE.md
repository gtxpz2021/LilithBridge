# 安装与使用说明

LilithBridge 是 **《不/存在的莉莉丝》（The NOexistenceN of Lilith）** 的非官方 MOD，用来扩展莉莉丝的日常对话与记忆。本页从准备游戏到保存 API 配置，说明当前公开预览的安装路径。

只想了解设计、不打算安装？直接读[架构入门](../ARCHITECTURE.md)，不需要购买游戏。

## 1. 先找对游戏，再确认能否安装

[《不/存在的莉莉丝》Steam 官方商店](https://store.steampowered.com/app/4643090/?l=schinese)是游戏的购买入口，购买后通过 Steam 下载。请认准 **App ID 4643090**。

[《不/存在的你，和我》（The NOexistenceN of you AND me）](https://store.steampowered.com/app/2873080/?l=schinese)是另一款游戏，App ID 为 2873080。它不是本 MOD 的安装目标，也不是安装前置，无需为了安装 MOD 而另购它。

当前预览的要求：

| 项目 | 要求 |
|---|---|
| 系统 | Windows x64 |
| 游戏 | 《不/存在的莉莉丝》1.0.4 的已核验文件组合 |
| 加载环境 | 匹配的 BepInEx、interop 和运行依赖，需另行准备 |
| 最终检查 | 由安装器检查游戏与配套文件是否匹配 |

**如果你只有 Steam 1.1.0 或其他不匹配版本，现在先不要安装这个预览。** 商店是正版获取入口，不保证提供本 MOD 要求的 1.0.4 文件组合。若环境不匹配，请等待对应版本的 MOD，不要修改校验清单强行安装。

BepInEx 与 interop 不在包里。准备方式和固定版本见[依赖说明](DEPENDENCIES.md)；已有加载环境时，不要直接覆盖成别的构建。

## 2. 下载 MOD 安装包

打开 [preview-20261029 预览发布页](https://github.com/gtxpz2021/LilithBridge/releases/tag/preview-20261029)，下载附件：

`LilithBridge-6a028692-win-x64-private-candidate-r1.zip`

这是已经公开的预览附件，文件名保留了原来的候选标识。`Source code (zip)`、`Source code (tar.gz)` 和仓库 “Download ZIP” 都是源码，不含可直接安装的插件 DLL 与安装器 EXE。

安装前先备份自己的游戏、配置和存档。[技术附录](TECHNICAL-NOTES.md)列出了这份预览已完成和仍待完成的验证。

## 3. 安装插件并保存自己的 API 配置

1. **退出游戏，完整解压安装包。** 保持文件夹结构，不要只提取安装器 EXE，也不要直接在压缩包里运行。
2. **运行 `Start-Setup.cmd`。** 点击“选择游戏目录…”，选择含 `Lilith.exe` 的《不/存在的莉莉丝》目录，再点击“检查”。Steam 用户可从游戏的“管理 → 浏览本地文件”找到目录。主窗口未选目录时可能显示通用模板说明，选好后以实际检查结果为准。
3. **核对改动。** 检查目标目录、独立数据目录及将替换的文件。检查通过后，勾选确认并点击“安装并打开配置”。缺文件或摘要不符时，按提示核对相应文件。
4. **填写自己的聊天 API。** 在配置器填写 HTTPS 服务地址、模型名和 Key；核对保存目录，勾选“我确认这是要配置的新纯净副本，允许保存到上面显示的配置目录”，再点击保存。**只使用远程聊天 API 不需要 Python，先保持本地召回关闭即可。**
5. **启动游戏。** 保存后，从所选游戏目录运行 `Lilith.exe`。安装器不会代你启动游戏，配置器也不会预先调用 API 测试。

## API Key 与配置保存

API Key 以明文保存在本机，备份也可能保留旧 Key；不要把使用后的配置目录、备份或整份游戏副本发给别人。

已有 Key 不回显，输入框留空表示保留，不是删除。要删除时，明确选择“清除当前有效 Key”。选了路径或填了文字但尚未保存，只是修改草稿；保存后以界面给出的结果为准。

## 本地召回：需要时再加

本地语义召回帮助从旧经历中找相关内容，不负责生成聊天回复。可以先不启用；其他历史和记忆行为仍取决于配置。

当前安装包已包含生产 worker，但**不含 Python 环境或模型权重，也不会自动下载**。按[依赖说明](DEPENDENCIES.md)准备完成后，在配置器选择：

- 自己准备的 venv 中的 `Scripts/python.exe`；
- `optional/semantic-worker/semantic_worker.py`；
- 固定 BGE 模型的权重目录，其中应恰好包含清单要求的 11 个文件及其子目录。

模型目录不是解压包的外层：如果你取得的模型包外层放有说明和许可证、内层为 `bge-small-zh-v1.5/`，请选择这个**内层目录**。保留清单要求的官方 `README.md`，不要用外层说明覆盖它，也不要加入清单之外的 LICENSE 或其他文件。

worker 旁的 `model-manifest.json` 必须保留。**不要选择 `optional-recall/probe-fixture/semantic_worker.py`：它是合成自检夹具，不是游戏配置入口。**

保存本地召回设置按这个顺序操作：**选择模型、Python 和 worker 路径 → 明确选择“关闭本地召回” → 勾选配置确认并保存 → 重新读取 → 检查本地文件 → 选择启用 → 再次勾选配置确认并保存。** 更换任一路径时，也按这个顺序重新设置。

## 数据与回退

安装、恢复或回退前，先查看对应改动预览。遇到文件冲突、权限问题或游戏仍在运行时，停止处理，不要强制覆盖。

升级与回退只管理清单中的插件文件，保留用户配置、记忆、原生存档及其他 MOD。插件的独立数据目录与游戏原生存档不同：原生存档仍可能按 Windows 账户共用，另建游戏副本不会自动隔离它。

需要撤回安装时，选择“预览最近回退”，核对事务与改动，再明确确认执行；取消预览不会执行回退。不要直接删掉备份或事务目录来代替回退。
