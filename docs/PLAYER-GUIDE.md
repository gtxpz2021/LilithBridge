# 安装与使用说明

本页说明如何使用 [Releases 中实际发布的安装包](https://github.com/gtxpz2021/LilithBridge/releases)。源码 ZIP 不含安装器 EXE 或插件 DLL；请勿把源码目录当成安装目录。

这份包围绕《不/存在的你，和我》中的莉莉丝扩展日常对话与记忆。想先了解项目，可以读[首页](../README.md)的聊天示意；只看设计而不安装游戏，则从[架构入门](../ARCHITECTURE.md)开始。

## 先确认你有匹配的游戏环境

当前安装候选只支持已验证的 **1.0.4 游戏及其配套环境**，运行于 Windows x64。安装器会核对 32 个前置文件，全部符合才放行。其他版本、未知文件组合和 Steam 1.1.0 不能用这份包安装。

游戏、BepInEx、interop 和相应运行依赖不包含在包里，需要你另行准备。缺文件或检查不匹配时，按提示核对具体文件，不要改清单、跳过检查或覆盖现有加载器。取得入口和要求见[依赖说明](DEPENDENCIES.md)。

安装、配置保存与回退已经过手工界面验证，完整游戏启动尚未完成验证。请保留自己的备份，并把它视为限定环境下的私有安装候选。

## 安装插件并配置远程 API

1. **退出游戏，解压整个包。** 保持文件夹结构，不要单独移动安装器 EXE。
2. **打开 `Start-Setup.cmd`。** 选择你自己的匹配游戏目录，然后检查。主窗口未选目录时可能还显示通用模板说明；选好后以实际检查结果为准。
3. **核对改动。** 查看目标目录、独立数据目录和将替换的文件。确认无误后，勾选确认并点击“安装并打开配置”。
4. **填写自己的聊天 API。** 在配置器填写服务地址、模型名和 Key，核对保存目录后主动保存。安装器和配置器不会调用 API 测试，也不会替你启动游戏。

**只使用远程聊天 API 不需要 Python。** 可以先不配置本地召回，不用为了完成安装而准备模型或运行可选工具。

## API Key 与配置保存

配置器会真实写入配置。API Key 以明文保存在本机，备份也可能保留旧 Key；不要把使用后的配置目录、备份或整份游戏副本发给别人。

已有 Key 不回显，输入框留空表示保留，不是删除。要删除时，需要明确选择“清除当前有效 Key”。保存后以界面给出的结果为准；选了路径或填了文字但尚未保存，只是修改草稿。

## 想用本地语义召回时再做这一步

本地召回用于从旧经历中寻找相关内容，不负责生成聊天回复。不启用它，就少了这条按意思查找旧事的通路；其他历史和记忆行为仍取决于配置。

包内已经有生产 worker，但 Python 环境和模型要另行准备。请先读[依赖与本地召回说明](DEPENDENCIES.md)，再在配置器里选择：

- 自己准备的 venv 中的 `Scripts/python.exe`；
- `optional/semantic-worker/semantic_worker.py`；
- 按固定清单取得的 BGE 模型目录。

worker 旁边的 `model-manifest.json` 必须保留。**不要选择 `optional-recall/probe-fixture/semantic_worker.py`：它只是自检用的合成示例。** 安装器不会替你部署 worker、安装 Python、下载模型或自动启用召回。

更换模型、Python 或 worker 路径时，先明确关闭召回并保存，再重新读取、检查，最后主动启用。静态文件检查通过不代表模型运行成功；已完成的独立 worker 验证也不能代替这份插件的完整游戏接入验证。

## 数据与回退

安装器按清单管理自己的插件文件。执行安装、恢复或回退前，都先查看对应改动预览；遇到文件冲突、权限问题或游戏仍在运行时，停止处理，不要强制覆盖。

升级与回退会保留用户配置、记忆、原生存档及其他 mod。插件的独立数据目录与游戏原生存档不同：原生存档仍可能按 Windows 账户共用，另建游戏副本不会自动隔离它。

需要撤回一次安装时，使用安装器中的“预览最近回退”，核对事务与改动，再明确确认执行；取消预览不会执行回退。不要直接删掉备份或事务目录来代替回退。

精确支持范围、文件身份和验证记录见[技术附录](TECHNICAL-NOTES.md)。
