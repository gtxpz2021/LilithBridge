# 安装与使用说明

LilithBridge 为 **《不/存在的莉莉丝》（The NOexistenceN of Lilith）** 扩展日常对话与记忆。第一次使用，可以先把聊天配好，本地召回以后再加。

## 1. 安装前准备

| 项目 | 需要什么 |
|---|---|
| 系统 | Windows x64 |
| 游戏 | 正版[《不/存在的莉莉丝》](https://store.steampowered.com/app/4643090/?l=schinese)，Steam App ID 4643090 |
| 加载环境 | BepInEx 的 Unity IL2CPP Windows x64 加载器，以及首次启动生成的 interop 文件，见[依赖说明](DEPENDENCIES.md) |
| 聊天服务 | 自己的 DeepSeek API Key；费用与数据处理规则以服务商说明为准 |

安装器会检查所选游戏目录及运行所需组件，不只看游戏版本号。检查不通过时，先按提示处理；不同游戏版本和更新仍可能存在兼容问题。

首次给原版游戏装 MOD，在向导内勾选自动准备官方加载环境。需要生成运行文件时，**按提示主动运行一次游戏，再退出继续。** 已有健康加载环境会复用。

安装前请备份自己的配置、记忆和游戏存档。插件有独立数据目录，但**原作存档仍可能由同一 Windows 账户下的游戏副本共用**；复制游戏目录不会自动隔离原作存档。

## 2. 下载安装包

打开 [Releases](https://github.com/gtxpz2021/LilithBridge/releases)，阅读对应发布说明，下载 **Windows 安装 ZIP 附件**。

“Source code (zip)”“Source code (tar.gz)”和仓库的“Download ZIP”都是源码，没有可直接运行的安装器与插件。

## 3. 安装插件和配置

1. **完整解压，运行 `Start-Setup.cmd`。** 选择 `Lilith.exe` 所在游戏目录。Steam 的“管理 → 浏览本地文件”可以帮助找到它。
2. **选择组件与服务。** 勾选插件、自动准备加载环境；需要本地召回时再选本地召回，Python、环境与固定 BGE 模型一起准备。保留默认的 DeepSeek 官方 / deepseek-flash，并填写自己的 Key；原有 Key 留空可保留。
3. **核对计划，点“开始安装”。** 向导显示来源、下载量和进度；缓存中完整的组件会复用。需要首次运行生成 interop 时，按提示主动运行游戏并退出，再点“继续安装”。
4. **确认完成，再进游戏。** 角色进入桌面场景、保持清醒且原作选项菜单关闭后，按回车打开聊天输入框。看到输入框即可确认交互入口可用。保存配置本身不调用对话 API。

已有数据根、记忆和自定义索引路径会保留；本地召回准备通过后，最终路径与启用状态一次保存。游戏版本变化不要求重新填写 Key；实际接口满足时继续使用。项目新版本可在向导的“项目更新”检查并确认应用，游戏运行时先等待退出，不强杀游戏。

### 想换模型或服务

- **DeepSeek Pro**：可以在模型列表中选择 Pro（`deepseek-v4-pro`）。费用以服务商说明为准。
- **其他服务**：使用自定义高级入口，按服务商文档填写 HTTPS API 地址、模型标识和该服务的 Key。不同服务的接口行为可能有差异，兼容要求见[依赖说明](DEPENDENCIES.md#远程聊天-api)。

初次使用可以先保留默认设置，确认基本聊天可用后再调整。

## API 费用与 Key

API 可能按使用量收费。聊天时，你的发言和本次选入的历史材料会发送到所选服务；使用前请阅读它的价格与数据处理说明，并确认自己的账户可用。

**Key 以明文保存在本机，配置备份也可能含有旧 Key。** 请勿公开配置、备份、记忆目录或使用过的整份游戏副本。反馈问题时，优先提供错误提示，并检查截图中是否包含 Key 或私人聊天。

修改配置时，已有 Key 不会显示出来：

- 继续使用同一服务时，Key 输入框留空可保留现有 Key。
- 要替换 Key，填入新 Key 后保存；要删除，明确选择清除后保存。
- 换服务商时，请填写新服务的 Key，不能沿用上一家服务的 Key。

改完内容后须保存；取消不会写入。再次编辑前，重新读取当前配置。

## 本地召回：需要时再加

本地召回帮助寻找意思相关的旧经历，聊天回复仍由选定的远程 API 生成。在向导内勾选本地召回即可一起准备私有 Python、环境、固定模型并本地核验，普通用户不需要手选 Python 或模型目录。未选择本地召回会保留现状。

已在 Steam 1.1.0 的实际聊天中验证本地召回接入，相关旧材料可以被选入本次对话。它不保证每次提问都能找到合适的记忆，也不代表任意游戏版本都兼容。在线下载等尚待验证的范围见[本版说明](RELEASE-NOTES-unified-r3.md)。

## 常见问题

| 遇到的情况 | 下一步 |
|---|---|
| 找不到 `Lilith.exe` | 从 Steam 的“管理 → 浏览本地文件”打开游戏目录，再重新选择。 |
| 提示缺少加载器或 interop 文件 | 按[依赖说明](DEPENDENCIES.md)准备官方加载器；首次启动游戏生成文件，退出后再检查。 |
| 提示当前环境不支持 | 先核对游戏与加载器是否符合发布说明。保留原文件，不要修改清单或覆盖加载器来强行通过。 |
| 提示游戏正在运行、文件被占用 | 正常退出游戏及占用程序，再检查。 |
| 提示没有写入权限 | 检查所选目录及权限，或选择自己有权限的游戏副本。 |
| 提示重复或未知插件 | 先备份并核对现有 LilithBridge 插件，保留当前文件，避免反复覆盖。 |
| 配置保存失败或结果不明确 | 重新读取当前配置，再按提示处理；不要立即重复提交。 |
| 回车没有打开输入框 | 确认角色已进入桌面场景、保持清醒，且原作选项菜单已关闭。若仍无反应，退出游戏并检查插件是否安装到了实际启动的目录。 |
| 输入后没有正常回复 | 核对服务商、模型、Key、网络与服务商账户状态。反复重试前查看错误提示，避免产生不必要的调用费用。 |
| 本地召回检查失败 | 保持召回关闭，核对 Python、worker 和模型路径；可以先使用远程聊天。 |

## 中断恢复与回退

如果安装器提示存在未完成的安装，先预览中断恢复，核对目标目录与文件，确认后再执行。恢复完成后重新检查。

需要撤回最近一次安装时，选择“预览最近回退”，查看将恢复的文件，再确认执行。取消预览不会改动文件。若提示冲突，先保留现状和备份，不要强行覆盖或删除事务目录。

回退只处理安装器管理的插件文件；配置、记忆、原作存档及其他 MOD 会保留。它不会撤销游戏过程中对原作存档的修改。
