# 安装与使用说明

LilithBridge 为 **《不/存在的莉莉丝》（The NOexistenceN of Lilith）** 扩展日常对话与记忆。本页对应公开预览 [preview-20261029](https://github.com/gtxpz2021/LilithBridge/releases/tag/preview-20261029)。

## 1. 确认能否安装

| 项目 | 当前要求 |
|---|---|
| 系统 | Windows x64 |
| 游戏 | [《不/存在的莉莉丝》](https://store.steampowered.com/app/4643090/?l=schinese)，Steam App ID 4643090；1.0.4 的指定文件组合 |
| 加载环境 | 匹配的 BepInEx、interop 和运行依赖，需要自行准备，见[依赖说明](DEPENDENCIES.md) |
| 聊天服务 | 自己的 API 地址、模型名和 Key；费用与数据处理规则以服务商说明为准 |

**这个安装包不支持 Steam 1.1.0。** Steam 商店提供正版游戏，但当前下载版本未必符合这个预览的要求。若你没有匹配环境，请等待支持自己版本的安装包。

这仍是测试预览：安装、配置保存与回退已有检查，完整游戏启动与聊天尚未完成验证。安装前请备份自己的配置、记忆和游戏存档。

**关于存档：** 插件有独立数据目录，但原作存档仍可能由同一 Windows 账户下的游戏副本共用。复制一份游戏目录，不会自动隔离原作存档。

## 2. 下载安装包

在 [preview-20261029 发布页](https://github.com/gtxpz2021/LilithBridge/releases/tag/preview-20261029)下载：

`LilithBridge-6a028692-win-x64-private-candidate-r1.zip`

“Source code (zip)”“Source code (tar.gz)”和仓库的“Download ZIP”都是源码，没有可直接运行的安装器与插件。

## 3. 安装并保存配置

1. **退出游戏，完整解压安装包。** 保持文件夹结构，在解压后的目录操作。
2. **运行 `Start-Setup.cmd`。** 点击“选择游戏目录…”，选择含 `Lilith.exe` 的目录，再点击“检查”。在 Steam 中右键游戏，选择“管理 → 浏览本地文件”，可以找到这个目录。
3. **查看改动并安装。** 核对游戏目录、插件数据目录和将替换的文件。检查通过后，勾选确认，点击“安装并打开配置”。检查不通过时，先看下方的[常见问题](#常见问题)。
4. **填写聊天 API。** 填入服务商提供的 HTTPS API 地址、模型名和自己的 Key。先保持本地召回关闭，不用准备 Python 或本地模型。核对配置保存目录，勾选“我确认这是要配置的新纯净副本，允许保存到上面显示的配置目录”，再点击“保存配置”。
5. **确认保存结果，再启动游戏。** 保存成功后，从所选目录运行 `Lilith.exe`。本版安装器不会启动游戏，也不会替你试用 API；保存成功后仍需在游戏内确认能否正常聊天。

首次打开安装器、尚未选择目录时，可能看到“兼容性待核模板”的提示。选择目录并点击“检查”后，再查看具体结果。

## API 费用与 Key

API 可能按使用量收费。聊天时，你的发言和本次选入的历史材料会发送到所选服务；使用前请阅读它的价格与数据处理说明。兼容的接口形式见[依赖说明](DEPENDENCIES.md#远程聊天-api)。

**Key 以明文保存在本机，配置备份也可能含有旧 Key。** 请勿公开配置、备份、记忆目录或使用过的整份游戏副本。反馈问题时，优先提供错误提示，并检查截图中是否包含 Key 或私人聊天。

修改配置时，已有 Key 不会显示出来：

- 输入框留空：保留现有 Key。
- 填入新 Key：保存后替换。
- 要删除：勾选“明确清除当前有效 Key”，再保存。

改完内容后须点击“保存配置”；再次编辑前，点击“重新读取”。

## 本地召回：需要时再加

本地语义召回帮助寻找意思相关的旧经历，不负责生成聊天回复。可以先不启用，等基本聊天可用后再尝试。当前预览的本地召回游戏接入仍待实测。

准备与设置步骤统一放在[依赖说明](DEPENDENCIES.md#可选本地召回)，包括 Python、模型下载和路径选择。安装包已附带所需脚本，Python 和模型需另行准备。

## 常见问题

| 遇到的情况 | 下一步 |
|---|---|
| 找不到 `Lilith.exe` | 从 Steam 的“管理 → 浏览本地文件”打开游戏目录，再重新选择。 |
| 提示缺少依赖或版本不匹配 | 按[依赖说明](DEPENDENCIES.md)核对。若游戏为 1.1.0，请等待对应安装包；不要修改清单或覆盖加载器来强行通过检查。 |
| 提示游戏正在运行、文件被占用 | 正常退出游戏及占用程序，再检查。 |
| 提示没有写入权限 | 检查所选目录及权限，或选择自己有权限的游戏副本。 |
| 提示重复或未知插件 | 先备份并核对现有 LilithBridge 插件，保留当前文件，避免反复覆盖。 |
| 配置保存失败或结果不明确 | 点击“重新读取”确认当前配置，再按提示处理；不要立即重复提交。 |
| 游戏能打开，但聊天失败 | 先核对 API 地址、模型名、Key、网络和服务商账户状态。反复重试前查看错误提示，避免产生不必要的调用费用。 |
| 本地召回检查失败 | 保持召回关闭，核对 Python、worker 和模型路径；不影响你继续排查远程聊天配置。 |

## 中断恢复与回退

如果安装器提示存在未完成的安装，先预览中断恢复，核对目标目录与文件，确认后再执行。恢复完成后重新检查。

需要撤回最近一次安装时，选择“预览最近回退”，查看将恢复的文件，再确认执行。取消预览不会改动文件。若提示冲突，先保留现状和备份，不要强行覆盖或删除事务目录。

回退只处理安装器管理的插件文件；配置、记忆、原作存档及其他 MOD 会保留。它不会撤销游戏过程中对原作存档的修改。
