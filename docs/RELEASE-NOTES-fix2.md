## LilithBridge 0.3.150.66-rc.3.fix.2（预览修复版）

下载 `LilithBridge-unified-installer-20261103-rc3-fix2.zip`，完整解压，退出游戏后双击 `setup/LilithBridge-Installer.exe`。选择 Steam“管理 → 浏览本地文件”打开的游戏目录。已有配置、Key 与记忆沿用原数据目录；升级前备份实际数据目录和存档，健康的召回环境无需重装。

本版修复：
- 可选召回环境因发行夹具换行转换而校验失败。
- 1.2.x 分层桌面窗口中，回车打开的输入框落到屏幕外。
- 关闭启动日志控制台连同游戏退出：安装器默认关闭该控制台，插件安全分离已有或继承的控制台；文件日志保留，启动失败有图形提示。
- 保留未完成反思 Work 升级至本版；能力绑定准确 DLL，未知格式仍停止保护。
- 过期 interop 不再凭旧签名相同直接放行。需先在所选游戏中完成匹配生成、退出后重检；关闭自动生成或使用未验证路径时明确提示，不删除缓存或擅改生成设置。

**已知问题：历史记录窗口可能只显示一半，尚未修复。** 多显示器、高 DPI、任意旧加载器及将来原作版本不作全面兼容承诺。

验证覆盖旧 RC3 的数据保留升级、过期缓存门控、Work 恢复保护，以及 fix2 控制台分离的隔离运行；独立正常升级案例为原作 1.0.4→1.2.1。用户此前确认的正常安装/召回/对话来自 fix1，不能算作 fix2 的用户实测。未扩展外部聊天 API 与完整长期回归。

产品 DLL 保持 `08cef63c6315d9564f59f8d97b510c4671e4eb5ed7e71ca3e21fde76f8755bd7`，信息版本 `0.3.150.66-rc.3.fix.2`，数值版 `0.3.150.66`；安装器 `0.1.3.0`。旧安装器通过已校验包接续新版安装器，未保存的 Key 需重新填写，不跨进程传递。

这是 prerelease。旧发布保留；游戏、角色素材、生成的 interop、Python、模型及私人配置/对话/存档不随包分发。摘要见同页 `SHA256SUMS.txt`；源码与[升级边界](https://github.com/gtxpz2021/LilithBridge/blob/preview-20261103-rc3-fix2/docs/UPGRADE-COMPATIBILITY-fix2.md)对应本标签。
