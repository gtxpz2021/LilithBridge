# LilithBridge 一体化安装向导

下载 Windows 安装 ZIP，完整解压后运行 `Start-Setup.cmd`。选择游戏目录、所需组件与自己的 API Key，核对计划后开始。插件、加载环境和可选的本地召回环境由同一向导准备；需要首次生成游戏运行文件时，按提示主动启动游戏并退出，再继续安装。

已有 Key、数据目录、记忆和健康的本地召回环境会保留或复用。游戏更新后按实际所需接口检查，不因版本号变化就要求重新配置，也不保证所有未来版本都兼容。项目更新需要在向导内检查并确认；运行中的游戏须先正常退出。

## 当前验证范围

已在 Windows x64、Steam 1.1.0 中完成安装、启动、聊天回复交付和本地召回接入；召回材料已实际用于聊天。没有合适材料时，召回不应被理解为保证命中。

本次依赖准备使用已核验缓存。**安装器在线 HTTPS 下载、Range 断点续传及缺少 VC 运行库的全新 Windows 环境仍待验证；本次也未留存 GitHub 更新检查结果。** 因此暂不宣称全新电脑在线安装、更新的完整流程已经通过验证。

先按[最短使用步骤](../QUICK-START.md)安装；遇到问题时，参考[当前验证范围与已知限制](../CANDIDATE-VALIDATION.md)。下载问题可运行包内 `Network-Diagnostic.cmd` 获取脱敏报告。
