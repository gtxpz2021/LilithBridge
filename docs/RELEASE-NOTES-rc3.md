# LilithBridge 0.3.150.64-rc.3 预览

本阶段以 RC3 为基线收口。下载 Windows 一体化安装 ZIP，完整解压后打开 `Start-Setup.cmd`；首次使用方法仍是选择游戏目录、组件和自己的 API Key，核对计划后安装。旧版发布和资产保留。

## 本次改动

- 写入结果按项目保留已确认、未确认和未处理事实，后续回答使用实际结果。未确认可能已写入，不等于仍在处理；未处理不表示排队。桥接调用返回后不承诺本轮自动继续、重试或整批重写；玩家另提请求时仍可自然提供帮助。
- 最终发送前复核来源与供给范围，撤回/删除的材料不能因后台工作或恢复继续沿用；普通探索喜好的提问不受禁用。
- 安装器根据实际 DLL 字节检查未结反思 Work 的接手资格；未知/不兼容时保留工作并说明阻断原因，停稳后重新核查。配置、记忆与原作存档不跟随插件回退。保证限于所选宿主、已确定数据根和没有其他宿主并发写入；共享根、启动器另设路径等不在本次保证内，也不宣称全面历史兼容。
- 同一同步请求准备范围内复用相同正文的分词结果，并减少双字符分词的中间字符串；资格、排除、预算和角色仍各算。没有跨请求可读性/撤回缓存。分配量有改善，未据此宣称 Unity 帧时或长期流畅性通过；历史 2ms 仅作参考，已不作为硬验收线。

## 实际验证及边界

Steam 1.1.0 的一个合成预置案例实际完成：更正主聊、原调度自然反思、原生显示/history、正常退出重启、后续取回。两次主聊加一次反思，共 3 次 HTTP、3 份真实回包，无采样重试；合计输入 12,976、输出 254、总计 13,230 tokens。更正的 3 段与取回的 5 段分别与 history 文字、事件 ID、来源一致。旧理解 superseded，新理解 active 且进入重启后的真实请求。

初始经历和旧理解是明确标识的合成预置。本例是跨重启，尚非跨日或长期稳定性验证；显示证据是原生事件回执与 history，不是像素截图或人工目视认证。原调度 `test=False` 自然触发已有实证，但最终全部机会资格变量未留齐，不从 `new_turns=2` 推断绕过六行门槛。

本例关闭语义召回、视觉、截图、应用感知和主动闲聊，有限原生运行状态经用户授权；不代表默认多模态或所有召回配置。原生目录、typed prefs、日用插件数据和原游戏文件/四项临时部署均完成恢复核验；私人原件、密钥、完整原始提示和内部报告不公开。Cloud 由用户决定，发布不改变设置。

该次实际链使用临时 Doorstop `ignore_disable_switch=true` 适配，已恢复原游戏目录；本包及生产安装器默认值未改，不将该案例当作默认安装或全部启动方式验收。既有安装器在线下载、Range 续传、全新电脑和完整在线更新链的未覆盖边界继续保留，详见 [CANDIDATE-VALIDATION.md](../CANDIDATE-VALIDATION.md)。
