**让今天的对话，成为明天相处的一部分。**

LilithBridge 是桌面伴侣游戏[《不/存在的莉莉丝》](https://store.steampowered.com/app/4643090/?l=schinese)的非官方开源 MOD。它把游戏里的莉莉丝、云端大语言模型与一套为真实长期相处从头设计的本机连续性记忆架构接在一起——不是给桌宠硬塞一个套壳聊天框，而是让每一次真实说出口的交流、停顿、打断与分歧，真正沉淀为跨天延续的记忆与她自己的想法。

## 装上之后，桌面上的她会变成什么样？

- **随时开聊，随时插话**：在桌面按回车就能直接对话，原生气泡与姿态动作自然联动。你随时可以发新话打断她没说完的气泡——程序只记**真正显示到屏幕上的内容**，绝不会让没说出口的后半句假装“我们聊过”。
- **不止“记得你”，还会自己琢磨、自己改口**：没有好感度进度条，也没有把人定死的静态标签。她会在聊完歇口气时安静回看刚发生过的对话，沉淀自己的判断；当被新的经历说服，她会顺理成章地修订、补充，或在不再合时宜时把旧念头温和收起。
- **日常清爽不串戏，触及默契又能蹦出跨天火花**：纯打招呼或随口闲聊不会被几千字的旧长文带偏；聊到真正触及彼此分寸的话题时，她能自然想起对这段关系的理解。开启可选的本地语义召回后，还能在跨越词面的语境里冷不丁接上几天甚至几周前的联想火花。
- **不止“听你说”**：支持按需看屏、按需翻阅第一作回忆、在合适契机主动搭话（所有权限均可在游戏内独立开关）。此外源码中也预留了**实验性**的外部感官侧车接口（默认关闭，当前处于试验阶段）。
- **一键装、无损升、记忆全留本机**：单文件安装器开箱即用，老玩家覆盖升级**绝不清空**已有记忆库、配置文件、API Key 与登录态。

## 为什么它不只是个“套壳聊天框”？

市面上并不缺把大模型接进桌宠或角色扮演的粗放套壳方案，但它们大多绕不开同一批通病——聊三天就退化成复读机，要么失忆，要么被一堆生硬规则和臃肿上下文拖垮。LilithBridge 选择从第一性原理重做整条链路：

| 常见套壳 / 粗放做法 | LilithBridge 的做法 |
|---|---|
| **静态标签 + “仿生学”表演**：靠好感度数值、固定用户画像、定时器遗忘曲线假装“像真人” | **不搞仿生学，做真实的思想连续性**：原话归档不可篡改；主观理解独立存账、条条可溯源，靠新经历自然演化、修订或放下，而不是拿衰减计时器糊弄人 |
| **程序替模型说话**：命中某个旧词就用硬规则强行催促、用死板脚本替角色抢台词 | **绝不让程序替模型说话**：程序只负责把干净、有依据的线索找全并守好权限边界；这一轮提不提、用什么语气接，永远交给模型自己判断 |
| **整锅上下文乱炖**：无门槛向量 Top-K 把几十片残缺气泡、旧长文、未说完的草稿一并灌进提示词 | **结构压倒修辞**：交付实录与跨气泡无损归并 + 显著度与长文阻尼门控 + 前缀 KV 缓存友好，给上下文留出呼吸感 |
| **前台阻塞或盲目全塞**：每轮卡着等总结，或者扛着整本历史硬着头皮聊天 | **前台一步直答，后台异步消化**：日常对话零阻塞，反思、回顾与语义索引退居后台；真要深挖旧事，由模型按需主动调用工具翻阅 |

支撑这一切的四条核心工程设计：

1. **呈现与记忆解耦**：流式气泡只是屏幕演出，不是记忆单元。交付时按实际播出的文字落盘，回读时把同一轮被拆分的气泡无损拼回连贯段落；被打断的未播残稿仅短暂承接紧邻下一轮，检索期的临时表达交付完毕即干净退役。
2. **事实归档 × 主观演化双账本**：原始经历永久保真；`B1` 连续性判断、反思笔记、经验法则与关系理解独立保存并绑定来源出处。聊天间隙的事后回顾反思会按完整问答边界回看近期互动，支持自然形成新想法、修正旧判断（`revises`）、按情境细化分支（`qualify`）或温和收起（`settles`）。
3. **几何语义宽召回 × 四重边界校验**：可选的独立本地 `BGE-small-zh-v1.5` 进程结合特征白化、CSLS 校准、DPP 去冗余与多维联想火花负责把跨词面线索找全；随后经过来源权限、更正链、长文阻尼与显著度门控层层把关，最后交给模型自主裁决。
4. **前缀 KV 缓存友好 × 按需重访**：提示词按“固定静态前段 + 步进历史锚点 + 动态尾段”分层组织，显著保护现代推理服务的前缀缓存命中率；需要更早细节或完整想法原文时，模型可主动调用 `review_context` 与 `revisit_thought` 工具按需翻看。

想了解完整架构图、设计取舍与源码阅读地图，请移步 [**架构入门（ARCHITECTURE.md）**](ARCHITECTURE.md)。

## 3 步快速开始（首次安装与无损升级通用）

> [!IMPORTANT]
> 已经装过旧版的玩家直接运行新版安装器即可无损升级，**绝不会清空或覆盖**你现有的记忆库、配置文件、API Key 与登录态。开始前请先**正常退出游戏**。

1. **下载安装器**：前往 [**最新版发布页**](https://github.com/gtxpz2021/LilithBridge/releases/latest)，下载单个 **`LilithBridge-Setup-*.exe`**（面向官方游戏 **1.2.1 · Windows x64**，无需自行解压或拼合资源包）。
2. **一键安装 / 升级**：双击运行，核对自动识别到的游戏目录即可安装。默认只装核心插件与加载器就能直接开聊；想启用跨越词面的语义召回与联想火花，勾选向导里的 **「本地召回」** 即可（也可之后随时重开向导补装）。
3. **游戏内启用**：启动游戏，在画面右上角进入 **`⋯ → 模型与资料设置`**：
   - 配好你的模型（填入 DeepSeek / OpenAI API Key，或在 **「认证账户」** 点击 **`Continue with ChatGPT`** 完成浏览器登录）；
   - 点击顶部 **`推荐使用设置`** 补齐记忆与按需回看推荐项，回到桌面按 **回车键（Enter）** 即可开始聊天。

完整安装步骤、首次加载提示与常见问题排查见 [**安装与使用指南**](NORMAL-USE.zh-CN.md)。

## 支持的模型与可选扩展

| 接入方式 | 内置选项 | 适用说明 |
|---|---|---|
| **DeepSeek 官方 / 兼容接口** | `deepseek-flash`（支持看屏图文）、`deepseek-v4-pro`（纯文本）及自定义模型 ID | 使用自己的 API Key；主对话与后台记忆／反思可分别指定模型并调节思考档位；也支持在 `config.json` 中配置兼容的 Chat Completions 服务端点 |
| **Sign in with ChatGPT** | 浏览器官方授权后选用账户可用模型（如 `gpt-6.1-terra` 等目录模型） | 在游戏内「认证账户」页点 `Continue with ChatGPT` 登录，直接走账户订阅额度，**无需 API Key**；凭据以 Windows DPAPI 本机加密保存 |
| **OpenAI 官方 API** | `gpt-6.1-terra`、`gpt-6.1-sol`、`gpt-6-astra` 及自定义模型 ID | 通过官方 Responses API（`store=false`）接入，主对话与后台任务可独立配置模型、思考深度与输出上限；API Key 以 Windows DPAPI 本机加密保存 |

- **基础聊天不需要本地跑大模型**：向导里的 **「本地召回」** 是完全可选的轻量本地小模型（`BGE-small-zh-v1.5`），仅负责按语义找旧记忆与联想火花，不负责生成回复；不安装也能靠近期上下文与词面检索顺畅交流。
- **实验性扩展（感官侧车）**：源码已预留独立的桌面感官侧车宿主机与微反应节律接口，目前仍处于**实验性阶段**、默认关闭，不影响常规游玩与稳定性。

## 数据主权、工程边界与许可说明

- **记忆永远留在你的电脑上**：所有对话归档、`B1` 连续性数据库、反思笔记与语义索引均保存在本地 `LilithBridgeData/`（兼容旧版 `%APPDATA%\LilithAI`）。后台反思、看屏截图、第一作语料引用与临时表达均可在游戏内独立开关，升级绝不覆写既有选择。
- **透明的远程与能力边界**：与所有云端大模型应用一样，每次回复或后台整理会向你配置的模型服务商发送本轮实际选入上下文的材料。长期相处的细腻程度依然取决于所选模型本身的能力与召回命中率——我们不做“永不遗忘、永不误解”的空头承诺，但坚持每一条理解**有源可溯、有错可改**。
- **开源许可范围**：本项目自有 C# 源码、安装工具与文档采用根目录 [**MIT License**](LICENSE)。安装包随附的第一作整理语料以及 BepInEx、Python、BGE 等第三方组件保留各自原有权利、不归入 MIT 范围；公开源码仓库与源码包不包含游戏本体、原作语料正文及任何私人配置或凭据。详见 [**许可说明**](LICENSE-STATUS.md)。
