# LilithBridge

> To call up a demon, you must learn its name.

**让今天的对话，成为明天相处的一部分。**

LilithBridge 是桌面伴侣游戏[《不/存在的莉莉丝》](https://store.steampowered.com/app/4643090/?l=schinese)的非官方 MOD。它把游戏里的莉莉丝、大语言模型和本地连续性记忆接在一起：你可以直接跟她聊天、看屏互动，也让每一次真实说出口的交流、停顿与分歧，随时间沉淀成她对你的理解。

## 为什么不做一个“套壳聊天框”

很多桌面伴侣或角色扮演插件只需要一个输入框加上提示词就能跑起来，但那样往往聊十天还是像第一天认识，或者很快变成被标签绑死的复读机。LilithBridge 在架构上坚持四件事：

- **“气泡显示”只是呈现手段，不是记忆单元。** 流式长回复可能拆成很多个小气泡播完，也可能中途被你打断。程序一方面只按**实际交付到屏幕的部分**落盘，保证“她没说完的话不会假装说过”；另一方面在回看往事时把同一轮被拆分的气泡重新拼成完整语段，不让碎片回声挤占上下文注意力。
- **把“发生过什么”和“后来怎么理解”分开记账。** 原话归档保持真实不可篡改，后台反思形成的笔记、经验与关系理解独立保存并带有来源依据——可以修订、补充，也可以在不再合时宜时被温和地收起，而不是给玩家贴一个永久不变的静态人设标签。
- **“搜得宽”与“判得准”各司其职。** 词面线索与可选的本地 BGE 语义检索负责把相关经历和跨越词面的联想候选找全；随后经过来源、版本与相关性筛选，真正“要不要提、怎么接”交由模型结合当下语气自己判断，而不是用“检测到旧计划关键词就强制催促”的硬规则提线。
- **前台流畅聊天，后台异步消化，对缓存友好。** 日常交流不阻塞于后台整理，得空时才进行反思和按日梳理；提示词围绕前段稳定、后段动态、按需重访工具来分层组织，既兼顾响应速度与长程记忆，也能在大模型的上下文窗口里给真正有价值的新鲜线索留出位置。

> [!NOTE]
> 记忆与理解能发挥多少作用，依然受所选模型能力、对话上下文容量以及检索召回率影响——它不会“永远记得一切、从不误会”，但每一条理解都有源可溯、有错可改。

## 快速开始（首次安装与保留存档更新通用）

> [!IMPORTANT]
> 已经装过旧版的玩家直接用新版安装器即可无损升级，**绝不会清空或覆盖**你现有的记忆库、配置文件、API Key 与登录态。开始前请先**正常退出游戏**。

1. **下载安装器**：前往[**最新版发布页**](https://github.com/gtxpz2021/LilithBridge/releases/latest)，下载单个 **`LilithBridge-Setup-0.3.150.105-cn21-4de072f7.exe`**（面向官方游戏 **1.2.1 / Windows x64**，无需自行解压拼合资源包）。
2. **一键安装 / 升级**：双击运行，核对自动识别到的游戏目录（需要本地语义召回可勾选“本地召回”，默认仅装核心插件与加载器即可开聊），勾选确认后点击安装。
3. **游戏内启用**：启动游戏，在画面右上角进入 **`⋯ → 模型与资料设置`**：
   - 在 **对话模型 / 密钥与隐私** 选择 DeepSeek 并填入自己的 Key，或在 **认证账户** 点击 **`Continue with ChatGPT`** 完成浏览器登录，也可以填自定义 OpenAI 格式服务端点；
   - 点一次顶部的 **`推荐使用设置`** 确认记忆与按需回看选项，之后按 **回车键** 即可打开输入框开始聊天。

完整安装截图说明与常见问题排查见[**安装与使用指南**](NORMAL-USE.zh-CN.md)。

## 支持的模型与接入方式

| 接入方式 | 当前内置选项 | 适用说明 |
|---|---|---|
| **DeepSeek 官方** | `deepseek-flash`（支持图文）、`deepseek-v4-pro`（纯文本） | 使用自己的 API Key；主对话与后台任务可分别选模型，后台整理默认使用非思考模式以兼顾速度 |
| **Sign in with ChatGPT** | 浏览器登录后选用账户可用模型（优先 `gpt-6.1-terra` 等目录模型） | 在游戏内「认证账户」页点 `Continue with ChatGPT` 授权，直接走账户计划额度，无需 API Key |
| **OpenAI API / 自定义** | `gpt-6.1-terra`、`gpt-6.1-sol`、`gpt-6-astra` 及自定义模型 ID | 使用自己的 API Key 或兼容 HTTPS 接口，可按需要调节思考档位与输出上限 |

**基础聊天不需要本地跑大模型。** 向导里的「本地召回」是完全可选的本地小模型（`BGE-small-zh-v1.5`），仅负责按意思帮忙找旧记忆，不负责生成回复；关闭或暂不安装也能靠近期上下文和词面检索正常交流。

## 数据控制与许可边界

- **本地数据归你掌握**：记忆库（含 `LilithBridgeData/` 下的对话记录、B1 连续性数据库、反思笔记与索引）均留在你自己的电脑上。游戏内可随时单独开关后台整理、资料供给、作品片段与截图权限；升级安装不会覆写已有开关选择。
- **远程调用边界**：与任何云端大模型相同，每次生成回复或后台整理时，本次实际选入上下文的对话与材料会发送给你所配置的模型服务商。
- **开源许可范围**：本项目自有 C# 源码、安装工具与文档采用根目录 **MIT License**。安装包内附带的第一作整理语料（`first-game.collection.jsonl`）仅随安装程序分发用于按需引用，与 BepInEx、Python、BGE 等第三方组件一样保留各自权利、**不归入 MIT 范围**，公开源码仓库与源码压缩包中亦不包含游戏本体、原作语料正文及任何私人配置/凭据。详情见 [许可说明](LICENSE-STATUS.md)。
