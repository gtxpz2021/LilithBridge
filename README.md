# LilithBridge

> To call up a demon, you must learn its name.


LilithBridge 是桌面伴侣游戏《不/存在的莉莉丝》的非官方 MOD。它连接游戏中的莉莉丝、语言模型和本地记忆，让日常交流能够留下来，在以后的对话中继续发挥作用。

我们做这个项目，最在意的一件事是：你们相处过的经历，能不能逐渐影响她怎样理解你、怎样回应你。

聊过的小事可以在合适的时候被想起，过去的误会也应该有重新理解的机会。你今天改变了主意，不必因此抹掉昨天的自己；一句随口的抱怨，也不该轻易变成对你永久的判断。我们希望这种连续性容得下变化，让相处可以慢慢积累。

给理解留下依据，也留下余地

LilithBridge 把原始经历与后来形成的理解分开处理，保留来源和修订关系。相关旧事可以按文字线索或意思被找回来；反思机制可以依据经历整理、调整已有理解，再为后续交流提供材料。

连一句回复被打断时，程序也会按游戏中实际显示出的部分写入经历，避免下次默认那些尚未说完的话已经对你说过。这样的细节，是为了让后来的交流有尽可能可靠的来处。

我们的分工很明确：模型做模型的事，程序做程序的事。程序负责记录、检索、核对来源与安排交互；模型结合这些材料和你眼前的话，判断怎样回应。找到一段旧经历，并不意味着必须提起它；现在的你仍然重要。

你可以随口闲聊、吐槽、开玩笑，也可以有不同意见。我们希望莉莉丝有空间作出自然的回应，日常对话不必每轮都调用工具、总结关系，或者写成一篇抒情故事。一句普通而合适的话，也值得留下。

项目自有代码采用 MIT 许可。架构说明解释了这些机制怎样衔接，也提供了源码入口，方便理解和继续改进。

## 第一次使用

你需要 Windows x64、正版游戏和自己的聊天 API Key。安装器会检查所选游戏环境；游戏更新可能影响兼容性，遇到提示时请先按[依赖说明](docs/DEPENDENCIES.md)处理。

1. **准备游戏。** 安装[正版游戏](https://store.steampowered.com/app/4643090/?l=schinese)（Steam App ID 4643090）。在向导中勾选自动准备 BepInEx 加载环境；需要首次生成运行文件时，按提示主动运行一次游戏，再退出继续。已有健康组件会复用。
2. **下载安装包。** 在 [Releases](https://github.com/gtxpz2021/LilithBridge/releases) 中选择适合自己环境的 **Windows 安装 ZIP 附件**，以对应发布说明为准。“Source code”和仓库的“Download ZIP”是源码，不能直接安装。
3. **安装并配置。** 完整解压安装包，运行 `Start-Setup.cmd`，选择游戏目录，勾选插件、自动准备加载环境；需要时再选本地召回，Python、环境和模型会一起准备。默认使用 **DeepSeek 官方** 和 **deepseek-flash**，填写自己的 Key，核对计划后点“开始安装”。已有安装保留原数据根与设置；高级地址仍可展开配置。
4. **说第一句话。** 启动游戏，等角色进入桌面场景、保持清醒且原作选项菜单关闭后，按回车打开输入框，输入想说的话。[逐步安装与常见问题](docs/PLAYER-GUIDE.md)。

先用远程聊天 API 即可，**不需要 Python 或本地模型**。API 可能按用量收费；聊天内容和本次用到的历史材料会发送到你选择的服务。API Key 以明文保存在本机，请保管好配置和备份。

游戏更新时保留 Key、模型、记忆与索引；实际接口仍满足时可以继续使用。项目更新从向导的“项目更新”检查并由你确认应用，运行中的游戏不会被强行替换。

## 聊起来会是什么样

下面是说明设计的小例子，不是原作台词或运行实录。

> 前几天，你说：“最近想去那家旧书店。”  
> 今天，你说：“下午终于空下来了。”  
> 莉莉丝：“那家旧书店还想去吗？还是今天只想歇一会儿？”

项目希望她能接上之前的事，也给你留下改变主意的余地。你想聊别的，旧计划就不该占满眼前的对话；你随口说的一句话，也不必从此变成固定偏好。记忆是为了让来往更自然，而不是让你一边聊天，一边整理档案。
