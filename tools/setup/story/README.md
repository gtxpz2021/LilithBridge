`first-game.collection.jsonl` 是《The NOexistenceN of you AND me》的既有规范化本地语料：2076条、18个脚本，含17条command记录（读取器不把命令行作为对白），12条带项目人工检索别名。它不是用户实际相处记录、第二作语料、游戏本体或新人格配置。

来源是 `Lilith_Original_Corpus_20260826.zip` 的 `origins/first_game_all.jsonl`。2076条 `source_record` 与该原文件逐条一致；保留游戏、脚本、行号、原文/清理文本、命令与启发式角色字段。人工别名只在包装层，不当成原作逐字内容。具体hash见 `SOURCE.json`。

原整理说明：第一作发行材料中的Naninovel本地化文本没有带Author/@char的原始.nani源脚本，speaker/role系推断。当前所有 `attribution_verified`、`branch_path_known`、`script_order_is_execution_graph` 均为false；置信度不是校准概率，脚本顺序不是执行分支图，也不证明当前玩家经历。

## 安装与使用

统一安装向导提供“安装并配置随包第一作语料”。用户明确选中并核对计划后，仅在已确认数据根的 `private-story/first-game.collection.jsonl` 缺失时新增本文件；已有同名文件（包括不同内容）保持原位。文件不加入DLL回退删除表，插件失败/回退不删除已有或新准备的原作资料。

新/无既存选源且未显式禁用的配置，可在同一次向导提交中自动保存实际随包路径、启用本地库和按需读取，无需手填JSON/路径或再次到游戏里选库。已有非空选源或显式禁用默认保持；仅在用户另勾选有说明的切换选项时改用随包库，仍不覆盖原语料文件。

“允许所选模型使用这份作品资料”是单独的明确选择，只可打开作品资料域的模型使用许可；未勾选时不新增该许可，原有状态保留。不会连带开启OpenAI资料发送总许可、ChatGPT后台、私人记忆/对话/图片授权，不换服务商或代登录。若OpenAI既有总许可未开启，仍由本人在既有隐私页决定。登录/Key必须本人完成。

如固定目标已有不同语料，向导保留它，不将其冒充随包库去开启新许可；会明确报告冲突，不用旧配置或整份资料目录覆盖当前资料。游戏内既有手动选源仍可作为高级选择，正常新安装不依赖它。未选择向导语料选项时不新增或切换语料。

检索在本地进行，只可能将有限入选片段与来源/不确定性标记发给当前模型服务商；不会把整库塞进每轮上下文或当作玩家记忆导入。库含剧情剧透，沿用产品既有许可/剧透处理。
